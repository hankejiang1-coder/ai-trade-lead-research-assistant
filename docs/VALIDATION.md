## 离线检查

在项目目录运行：

```sh
python3 -B -m unittest discover -p 'test_*.py'
node test_ui.cjs
```

Node只用于开发者的UI脚本检查，不是应用运行必需条件。HTTP防护测试用临时本机端口和假凭据，不调用收费API。
